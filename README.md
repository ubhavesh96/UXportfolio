# Bhavesh Udhani · Product Designer Portfolio

Personal portfolio of Bhavesh Udhani, a product designer with 4 years of experience in enterprise, fintech, edtech and AI products.

## What's inside

- `index.html`: the whole website (layout, styles and GSAP animations)
- `portfolio-assets/`: profile photo and resume PDF
- `start-portfolio.bat`: runs the site locally on Windows at http://localhost:5000

## Run locally

Double-click `start-portfolio.bat`, or run this in the project folder:

```
python -m http.server 5000
```

Then open http://localhost:5000.

## Publish with GitHub Pages

Repository **Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save**.
The site goes live at `https://<your-username>.github.io/<repo-name>/`.
